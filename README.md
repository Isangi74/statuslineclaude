# statuslineclaude

A custom `statusLine` command for [Claude Code](https://claude.com/claude-code).

## What is this?

Claude Code lets you configure a `statusLine` command in `settings.json` that
renders a custom status line at the bottom of the terminal, fed with session
context (model, cost, working directory, git branch, etc.) via JSON on stdin.

This repo holds that script/config.
